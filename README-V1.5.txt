ENJIWS MUSIC V1.5 — GLOBAL MUSIC DISCOVERY

What's new:
- Global search combines Jamendo and Audius results.
- Audius-only search and Jamendo-only search are also available.
- Tap an Audius result to stream it through the existing Media3 player.
- Existing direct audio URL player and LRCLIB lyrics remain included.
- Original dark-green Enjiws Music interface is retained.

Setup:
1. Extract this ZIP into the existing project folder, preserving folder paths.
2. Replace files when prompted.
3. Commit and push the updated project.
4. Wait for GitHub Actions to finish, then download the Enjiws-Music-APK artifact.

Jamendo:
- Enter your own Jamendo client_id in the app as before.
- Jamendo-only search and Global search need a valid client_id for Jamendo results.
- Audius search does not require a user API key for ordinary read-only requests; public API limits may apply.

Notes:
- Audius and Jamendo catalogues do not guarantee availability of every commercial/mainstream release.
- Audius streaming uses its documented track stream endpoint.
- The source update has not been compiled on your device yet. Verify the GitHub Actions build before installing.
